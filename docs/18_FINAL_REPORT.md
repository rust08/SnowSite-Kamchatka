# Итоговый отчёт (2026-11-21)

## Готово
- Воспроизводимый старт: `npm run check` (хеш графа), 23 теста, `npm start`; запуск на Windows одним файлом `START.bat`.
- Корректные метрики: вывезено / не распределено отдельно, причины, пометка несопоставимости при разном объёме.
- Solver: регрет-greedy + локальный поиск; точный эталон (полный перебор) и зафиксированный контрпример к чистому greedy.
- UI: карта, таблица сравнения, правка кандидата, строгий импорт/экспорт, защита от XSS (проверено в браузере), телефон без горизонтальной прокрутки.
- README со скриншотами, 3-минутное демо, перечень ограничений.

## Осталось
- Первый push и запуск CI на GitHub (нужны ваши действия или токен).
- Проверка запуска на вашем Windows-ноутбуке.
- Сравнение нескольких новых площадок вместе, CAPEX/OPEX, очереди и смены, ограничения по тоннажу и высоте (P1/P2).
- Реальные данные: документы по площадкам, кадастр, дорожные паспорта — нужны у профильных ведомств.
- Выбор лицензии кода проекта.

## Допущения
Все точки, объёмы, вместимости, скорость и тариф — сценарные. Граф OSM — снимок 19.11.2026, не паспорт дорог. Оптимальность solver доказана только на малых тестах. Продукт не утверждает допустимость участка и экономию бюджета.
