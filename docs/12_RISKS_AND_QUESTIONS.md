# Технические риски, тупики и вопросы для будущих интервью

| Риск | Последствие | Как предупредить |
|---|---|---|
| «Кандидат» расположен на дороге, а не на пригодной земле | Ложная рекомендация места | Клик по узлу означает подъезд к гипотетической площадке, **не** географическую границу участка |
| Базы/полигоны из интервью имеют непроверенные координаты | Ложная карта | Использовать исключительно synthetic; создавать отдельный evidence registry позднее |
| Снег с реагентами / загрязнённый снег | Санитарный и природоохранный риск | Разделить snow type и legal screening, не делать «approved» |
| Несовместимость режима Север/Камчатка | Пропуск ограничений | Визуально фиксировать 2026 revision law, проверить дату/применимость |
| Отличия грузового маршрута от легкового OSM | Ложная доступность | Считать транзит только условным без паспортов и turn restrictions |
| Greedy неоптимален | Неверное ранжирование кандидатов | Малый oracle + локальные улучшения, не заявлять global optimum |
| Сокращение км при снижении обслуженного объёма | Ложная экономия | Лексикографический ranking, показать `unservedM3` |
| Условия строительства и эксплуатации неизвестны | Недооценён CAPEX/OPEX | Не включать деньги в первое сравнение, только сценарная транспортная составляющая |
| Новая инфраструктура отнимает время | Демо не закончено | Offline-first Node+Leaflet, расширения отдельно |
| Перегрузка карты 12k segments | UI не реагирует | Leaflet canvas; измерить FPS/рендер, упрощать геометрии только при необходимости |
| Смешивание лицензий OSM/код/подложка | Ошибки при публикации | Прочитать ODbL/Tilezen/Leaflet, сохранить attribution |
| Передача частных данных в публичный remote | Утечка | Remote Private, `.gitignore` и ручная проверка staged files |

## Вопросы к городу — не блокирующие первый demo

1. Какие площадки официально действуют в рассматриваемый сезон? Их фактические координаты, допустимые типы снега и правовое основание?
2. Где и в каком виде подтверждаются вместимость и пропускная способность площадки на смене?
3. Как регистрируются талоны, очередь самосвалов, время приёма и сопоставление с районом погрузки?
4. Где реальные районы образования валов и сколько снега из них вывозится по сменам?
5. Для каких видов снега и операций действуют ограничения в нынешних санитарных правилах?
6. Каковы фактические затраты на открытие, подготовку и эксплуатацию новых площадок?
7. Какие дороги допускают гружёные самосвалы с учётом массы, поворотов, уклонов и сезонных запретов?
8. Кого следует считать пользователем SnowSite: руководителя, дорожного планировщика или диспетчера снеговывоза?

Пока нет ответов, не блокировать полностью демонстрацию. **Но** не выдавать условные параметры за фактическую оптимизацию города.
