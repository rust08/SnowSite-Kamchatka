# Манифест переиспользования «Севера»

**Источник проекта:** `https://github.com/rust08/Sever-GitHub`, основная ветка `main`, осмотрено 20.11.2026. Исходный ZIP пользователя `Sever-GitHub-main.zip`. Не зависеть от того, что репозиторий в дальнейшем сменится или будет недоступен.

| Из «Севера» | Переиспользование | Статус / предупреждение |
|---|---|---|
| `data/city-network.json` | Скопирован целиком в `data/` | OSM snapshot `pkgo-27233df581c6` 2026-11-19, 9 983 nodes, 12 354 edges. Проверяется локальным SHA-256, карта **не** паспорт дорог |
| `backend/planner.mjs` → `haulRoadPaths` | Семантика `routable`, `oneway`, closed, directed paths. В SnowSite независимый `src/routing.mjs` | Старый модуль включает другой planner — не импортировать его целиком |
| `backend/haul.mjs` | Формулы кузов/масса/плотность; понимание погрузки/вывоза/разгрузки | На старте не включаем полноценную смену и очереди; описать это как ограничение |
| `public/vendor/leaflet.*` | Скопированы JS/CSS/Licence для офлайн-интерфейса | BSD-2-Clause, сохранить notice |
| `public/terrain-map.webp` | Заменена на подложку «Севера» 2560x2560 (границы тайлов z11: 662-672 x 1922-1932) | Условия и первичные источники в `data/CITY_SOURCES.md`; не использовать рельеф как уклоны дорог |

| `public/city-context.js` | Включён (4.3 МБ, грузится лениво на масштабе от 11.5): береговая линия, вода, леса, здания, контекстные дороги | Добавлено 21.11.2026 после замечания о качестве карты; данные OSM (ODbL), рельеф 2560x2560 из «Севера» |
| `backend/governance.mjs`, `registry.mjs`, договоры, техника | **Не копировать** — другая предметная область | У нового продукта нет юридического признания подрядчиков или полномочий |
| `research/*.zip`, `knowledge/` | Не копировать целиком | Точные исходники лишь по мере конкретной задачи; не тратить токены на все архивы |

## Рекомендуемая техника переноса функций

1. Найти точный нужный API существующей функции.
2. Извлечь маленький чистый модуль или перенести его алгоритмическую семантику в новый локальный файл.
3. Написать контрольные тесты и сохранить дату/source commit.
4. НЕ вводить Git submodule / общую внешнюю БД / HTTP-зависимость от сервера «Севера»: они замедляют самостоятельное демо.
5. Позже, если правда понадобится общая библиотека, обсудить версионированный npm-пакет отдельным ADR.

## Что уже проверено

- `npm run check` контролирует SHA-256 включённого файла сети: `0e0a464f7d92057fa5bbad634c083ad0c1923294597d989ead386b393acf7ad2`.
- `npm test` проверяет направленность, закрытия, загрузку вместимости, массу и запрет утверждать юридический статус.
- Сравнение на полной копии графа выполнялось локально; учебные объёмы и точки не реальные.

**Важно:** источник графа — OpenStreetMap, ODbL, а не муниципальный реестр. Уровень транзитной доступности гружёных самосвалов на конкретных улицах нуждается в проверке.
