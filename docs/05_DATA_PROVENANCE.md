## Путь к проверенным данным

Для реальных объектов нужна запись:

`site_id, geometry, legal_basis_document_id, operator, site_kind, allowed_snow_types, approved_capacity_m3, hours, entry_exit_constraints, evidence_url, evidence_date, reviewed_by, reviewed_at, source_license, verification_status`.

Иные поля для факторов риска: гидрология, геология, водоохранные зоны, ПЗЗ/ВРИ, собственность/аренда, дренаж, экологическая экспертиза и техпаспорта дорог. Отсутствие записи означает `unknown`, **не** `compliant`.
