# UX changelog

## v4.1 — 2026-11-21 (по ТЗ «SnowSite v4 → v4.1»)
**Баги.** BUG-01 параметры формы не теряются (единый источник истины, валидация у поля); BUG-02 ID не зависят от длины массива; BUG-03 устаревший ответ отбрасывается (revision + requestId + AbortController), статусы «Считаем / Изменено — пересчитайте / Готово / Ошибка»; BUG-04 сброс в два нажатия, импорт чужой версии сети отклоняется. METHOD-01 демо без нулевых рейсов (контроль: 167.098 / 108.556 / 122.648 км).

**UX.** Карта и результат на одном экране; легенда с формами и подписями; выбор варианта кнопками (aria-pressed, стрелки); агрегированные маршруты (сплошная — с грузом, пунктир — возврат, число рейсов); карточки по клику; предупреждение и красные кольца при недовывозе; главный вывод словами; километры сравниваются только при равном объёме; время и затраты движения — в раскрывающемся блоке; редактирование в выдвижной панели (Esc закрывает, без focus trap); окно «Как работает»; текстовое описание маршрутов; таблица с `th`; адаптив 1366×768, 390×844, 360×800 без горизонтальной прокрутки.

**Сознательно за границей MVP.** Одновременное добавление нескольких кандидатов; CAPEX/OPEX, очереди, погрузка/разгрузка, смены; новый оптимизатор; правовая проверка площадок; серверное хранение; проверка тремя людьми без пояснений (нужна от команды, здесь не выполнена).

**Проверка.** `npm test` — 39/39; `npm run check` — PASS; `tools/e2e.cjs` — браузерные проверки в Chromium (Linux). Firefox и Windows-ноутбук проверены только пользователем вручную.

## v4.1.1 — 2026-11-21
- Аудит доступности axe-core 4.10 (рабочий стол, телефон, открытая панель, диалог «Как работает»): замечаний нет, исправлено единственное — добавлен заголовок `h1` («SnowSite»). axe в зависимости проекта не добавлялся (запускался отдельно).
- `START.bat` упрощён до минимума: переходит в папку, включает автооткрытие браузера и запускает `node src/server.mjs`; окно не закрывается при ошибке (`pause`). На Windows не проверялся — ручной запуск описан в `README_FIRST.txt`.
