# Правовые и территориальные проверки — НЕ автоматическая сертификация

**Документ инженерной постановки; не юридическое заключение. Сверено по публичным источникам 20.11.2026.**

## СанПиН (актуальный риск)

П.34 СанПиН 2.1.3684-21 регулирует обращение со снегом, собираемым с территорий. Для районов Крайнего Севера и приравненных местностей поправка Постановлением Главного государственного санитарного врача РФ №25 от **10.09.2026** предусматривает отдельное послабление для складирования снега **без противогололёдных реагентов** без водонепроницаемого покрытия и обвалования; оно не является общим разрешением размещать снег где угодно. Запрещённые/ограниченные зоны по текущему тексту должны проверяться отдельно.

Актуализируемые источники:
- https://www.consultant.ru/law/hotdocs/95761.html
- https://sudact.ru/law/postanovlenie-glavnogo-gosudarstvennogo-sanitarnogo-vracha-rf-ot_1364/sanpin-2.1.3684-21/ii/
- https://www.garant.ru/products/ipo/prime/doc/414862682/

**Нельзя** вычислять `is_legally_permitted` по одному буферу до ручного официального решения. Соответствие только после проверки актуального текста, применимости, всех документов и конкретной площадки.

## Кадастр, земельные и экологические ограничения

Возможный минимальный чек-лист, не полный набор оснований:

1. Правообладатель, кадастровая принадлежность, площадь и согласие на размещение.
2. Разрешённое использование, территориальная зона и ПЗЗ действующей редакции.
3. Водные объекты, водоохранные зоны, источники питьевого водоснабжения, ограничения по сбору загрязнённого снега.
4. Вид снега и наличие противогололёдных реагентов; характер площадки (складирование / плавление / временная перегрузка).
5. Покрытие, водоотведение, доступ для тяжёлых машин, въезд/выезд и ограничения дорог.
6. Фактическая вместимость, резерв, максимальная пропускная способность постов и график работы.
7. Документы, подтверждающие возможность использования площадки в нужный период.

У каждого пункта хранить `status: unknown|needs_review|documented|conflict|inapplicable`, `source`, `date`, `reviewer`. `documented` означает наличие документа, но не автоматическое заключение о законности.

## Как показывать кандидата

- Подпись **«Логистический кандидат · допустимость не проверена»** всегда по умолчанию.
- Теоретические узлы дорожной сети без сведений о земельном участке НЕЛЬЗЯ изображать как утверждённый новый полигон.
- Для будущих объектов из интервью нужны подтверждённые координаты, документ, дата, статус строительства; публичная новость не заменяет акт допуска.
- В сценарном MVP `legalStatus` из пользовательского JSON не меняет статус продукта: API выдаёт `not_assessed`.
