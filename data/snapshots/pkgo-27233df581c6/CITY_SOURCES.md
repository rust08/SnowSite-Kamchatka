# Дорожная сеть Петропавловска-Камчатского

Основная карта использует **городской округ Петропавловск-Камчатский**, границу уровня 6 OpenStreetMap. Сеть вырезана по полигону округа, в том числе в местах пересечения дорог с границей. Источники — [граница округа](https://www.openstreetmap.org/relation/1783597), [региональный снимок Камчатского края OSM France](https://download.openstreetmap.fr/extracts/russia/far_eastern_federal_district/kamchatka_krai-latest.osm.pbf), [авторы и лицензия ODbL](https://www.openstreetmap.org/copyright).

Состав сети включает магистрали, городские улицы, их съезды, жилые, служебные и грунтовые автомобильные проезды (`service`, `track`). Сохраняются безымянные дороги и отдельные компоненты графа. Ограниченные по доступу участки остаются на карте. В первоначальный условный перечень работ входят дорожные классы от магистральных до жилых и неклассифицированных улиц. Служебные и грунтовые проезды в этот перечень автоматически не входят. Для планов служит поле `serviceRequired`, для переездов — `routable`. Узлы с отмеченными воротами, столбиками, шлагбаумами и подобными препятствиями консервативно закрывают прилегающие к ним участки; частные, целевые и иные явно ограниченные проезды исключены из маршрутизации. Автобусные маршруты сопоставлены по отношениям OSM, направления улиц учитывают явные oneway-теги и круглые перекрёстки. Противоположные направления отдельной проезжей части составляют отдельные задания. Проверка разрешённых манёвров, массы и габаритов техники требует дополнительных данных.

Участки с двумя раздельно нанесёнными проезжими частями участвуют в сумме длин отдельно. Охват полигоном относится к данным OSM на указанную дату. Состав муниципального контракта, место депо, перечень приоритетных подъездов и фактическое состояние проездов предстоит подтвердить с подрядчиком. База выбрана у существующих демонстрационных координат в основной связной части графа.

## Повторный импорт

Требуются Python 3.11+, pyosmium (`osmium`) и Shapely. Скачайте PBF по ссылке выше. В окружении импорта выполните:

```sh
python -m pip install osmium shapely
python tools/import_city.py kamchatka_krai-latest.osm.pbf data/city-network.json
```

Импортёр считывает полигон и отношения автобусных маршрутов из того же снимка, собирает геометрию дорог между перекрёстками и записывает идентификатор версии из SHA-256. Прежняя районная сеть в `network.json` служит контрольным примером для тестов.


## Распространение данных и рельеф

Производная дорожная база city-network.json распространяется на условиях [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). © OpenStreetMap contributors. Идентификаторы относятся к геометрии и дорогам OSM. Значения serviceRequired и routable рассчитаны импортёром по правилам этой модели.

Рельеф взят из [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/). Источники высот и батиметрии перечислены в [атрибуции Tilezen](https://github.com/tilezen/joerd/blob/master/docs/attribution.md). Скрипт tools/render_relief.py формирует автономный фон WebP из 56 тайлов Terrarium масштаба 11. Цвет и тени передают форму рельефа, линии дорог рисуются по отдельному векторному графу. Высоты этой подложки не являются измеренными уклонами отдельных проезжих частей.

Берега, водоёмы, леса и здания взяты из того же регионального снимка OpenStreetMap, что и дороги. После формирования высот запустите `python tools/render_basemap.py kamchatka_krai-latest.osm.pbf`. Скрипт совмещает затенение рельефа с береговой линией и создаёт автономные public/terrain-map.webp и public/city-context.js. На подробных масштабах карта рисует контуры из векторного слоя.
