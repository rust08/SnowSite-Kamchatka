02 / Настройка расчёта

Точная оптимизация (MILP)

Legacy проверяет только добавление по одной площадке, не доказывает оптимальность и не применяет настройки Top-K. Если нужны ограничения и перенос, используйте MILP.

Точный поиск по конечному каталогу. Требуется Python + SciPy. Расширенный JSON v1.

      Как это работает

      1. Откуда. Голубые точки — места, откуда нужно вывезти снег, и сколько его там.
      2. Куда. Оранжевые квадраты — условные действующие площадки, зелёные ромбы — места, которые мы рассматриваем как новые. Все они выдуманы для примера.
      3. Сравнение. Точный режим выбирает заданное число новых мест и ранжирует конфигурации. Действующие сохраняются, кроме явно заданных групп переноса. Без действующих — выбор с нуля. Legacy проверяет только по одному кандидату.
      Что считает модель
      • Путь по дорогам OSM туда и обратно с учётом односторонних участков и закрытий; вместимость площадок; объём кузова и масса груза.
      • Если снега больше, чем могут принять площадки, сначала важнее вывезти больше снега, и только потом — меньше километров.
      • Время и стоимость — только за движение, при заданных скорости и тарифе.
      Чего модель НЕ делает
      • Не проверяет, можно ли по закону и по санитарным нормам принимать снег на этом месте. Кандидат — только гипотеза для проверки по документам.
      • Не знает про очереди, погрузку и разгрузку, смены, повороты, фактическое состояние дорог. Редактор карты поддерживает сценарные лимиты рейсов и типы снега; расширенные транспортные профили и внутриплощадочный пробег задаются в JSON v1.
      • Точный режим использует MILP и доказуемое отсечение; при таймауте рейтинг предварительный. Оптимальность относится только к заданному каталогу и модели. Legacy — эвристика без доказательства.
      • Не считает «экономию бюджета». Километры и рубли движения — модельные значения на условных данных.
      Данные

      Дороги — снимок OpenStreetMap от 19.11.2026 (© OpenStreetMap contributors, ODbL), рельеф Mapzen/Tilezen. Площадки, объёмы, скорость и тариф — сценарные.
      Экспериментальный инструмент оценки транспортной логистики. Не утверждает правовой, санитарной или экологической пригодности площадок.
