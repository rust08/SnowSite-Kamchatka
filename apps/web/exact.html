01 / Входные данные

Точный расчёт MILP

Загрузите JSON запроса v1.0 с полным набором ограничений. При add, relocate и frontier применяется безопасный preset. Точность относится только к заданному каталогу и модели; правовой статус площадок не подтверждается.

Выберите файл запроса размером до 1 МБ.

02 / Результат

Ответ API

Проверьте rankingStatus и solver.status перед использованием результата. Вы можете скачать исходный JSON без преобразований.

Результат появится после расчёта.
Сценарный инструмент оценки логистики. Не подтверждает правовую, санитарную или экологическую пригодность площадок.
